### AyoAyo

The task was to implement the ayoayo game using a text based program.
The program is split into two files:

- my_list.py- containing the circular linked list and node classes
- Ayoayo.py - containing the game logic

To use the classes successfully, the main functions available to be called are:

- createPlayer: takes one parameter of the player’s name as a string and
  returns the player object.
- printBoard: takes no parameter and will print the current board
  information
- returnWinner: takes no parameter.If the game is ended, returns the winner
- playGame:Allows playing of the game. It takes two parameters, the player index (1 or 2), and the pit index (1 or 2…. or 6), both as integers.
